# 🧠 Boolean - Specializzazione Front-End
## Esercizi JavaScript: Array Avanzati e Manipolazione Dati

Questo repository contiene una serie di esercizi (snack) proposti nel corso di specializzazione Front-End di Boolean, con l’obiettivo di esercitarsi nella gestione di array di oggetti complessi in JavaScript, applicando metodi funzionali come map(), filter(), reduce() e sort().
Gli esercizi si concentrano sulla trasformazione, ordinamento e analisi dei dati, mantenendo un approccio funzionale e pulito al codice.
